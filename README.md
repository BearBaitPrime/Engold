# Engold

A resource and progression expansion built natively for Fabric 26.1.2. Engold expands world exploration, mining, and tool crafting by introducing unique ore variants, resource clumps, intermediate processing items, and upgraded gear tiers.

---

Key Features

Ores & Special Blocks
* Ores & Stone Variants: Discover Ancient Deepslate, Graphene Deepslate, and Nepherite Jade Ore buried deep in world terrain.
* Resource Clumps: Mine high-yield clump structures including Calamity Clump, Diamond Clump, Emerald Clump, Gold Clump, Iron Clump, and Mega Clump Flesh.

Tools & Equipment
* Graphene Pickaxe: A high-tier mining tool crafted from processed graphene.
* Reinforced Graphene Pickaxe: An upgraded pickaxe reinforced for maximum efficiency and durability.

Materials & Components
* Refined Minerals: Craft and process Graphene, Purified Graphene Ore, and Nepherite Jade.
* Crafting Ingredients: Utilize Minerals, Reinforcement Beams, and Stone Rubble in specialized recipes.

---

World Generation & Mechanics
* Natural Ore Spawning: Built-in worldgen parameters allow all custom ores and resource clumps to generate organically throughout survival worlds.
* Balanced Progression: Progress through resource gathering, component refining, and tool upgrading via custom recipes and advancements.
* Native Mixins: Enhanced gameplay logic powered by custom Fabric event hooks and mixins.
